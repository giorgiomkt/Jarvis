# JARVIS

Painel Pantera para o Ottocast P3 Lite do Jaguar F-TYPE P300 (Batmóvel).

- `app/src/main/assets/index.html`: o painel (gerado a partir do protótipo).
- `MainActivity`: tela cheia, voz nativa (ouvir e falar), links para Waze e Spotify, playlist ao ligar.
- `BootReceiver`: abre o JARVIS quando o Ottocast liga.

Cada push na `main` compila `JARVIS.apk` em Actions › Build JARVIS › Artifacts.
